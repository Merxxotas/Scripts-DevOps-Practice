# Lab 1 — Discovery and Dry Run

Goal: verify the script runs and dry-run makes no request.

1. Run `./health_check.sh --help` and read the flags.
2. Run `./health_check.sh --dry-run` and confirm no network call.
3. Run `./health_check.sh --dry-run -v` and observe the verbose diagnostic.

Expected: exit 0 in all cases.
